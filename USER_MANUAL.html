1. Pengenalan

Sistem Pinjaman Aset ICT membolehkan pengurusan pinjaman aset seperti laptop, projector, tablet, dan lain-lain dengan mudah menggunakan QR code.

Ciri-ciri Utama:
  • Track status aset secara real-time
  • Scan QR code untuk pinjaman/pemulangan cepat
  • Rekod peminjam dan sejarah pinjaman
  • Laporan dan export CSV

2. Akses Sistem

2.1 Dari Komputer

  1. Buka browser (Chrome, Firefox, Edge)
  2. Masukkan URL:
    http://10.142.10.237/asset-loan/
  3. Login dengan username dan password

2.2 Dari Phone/Tablet

  1. Pastikan device connect ke WiFi yang sama dengan server
  2. Buka browser dan masukkan URL yang sama
  3. Atau scan QR code pada aset terus
Penting: Phone mesti pada network yang sama (WiFi/LAN) untuk boleh access sistem.

2.3 Test Connection

Untuk verify phone boleh access sistem, buka:

http://10.142.10.237/asset-loan/test.php

Jika nampak "Connected Successfully", bermakna connection OK.

4. Workflow QR Code

Workflow 1: Pinjam Aset (Scan QR)

  1. Buka camera phone, scan QR code pada aset
  2. Tap link notification untuk buka page aset
  3. Tekan butang "Loan This Asset"
  4. Pilih Existing Borrower atau New Borrower
  5. Isi maklumat:
    • Peminjam (atau create baru)
    • Tarikh pinjaman & due date
    • Condition aset (Excellent/Good/Fair)
    • Notes (optional)
  6. Tekan "Issue Loan"
  7. Aset status akan bertukar ke "On Loan"

Workflow 2: Pulangkan Aset (Scan QR)

  1. Scan QR code pada aset
  2. Page akan show info pinjaman semasa
  3. Tekan butang "Return This Asset"
  4. Isi maklumat:
    • Tarikh pemulangan (default: hari ini)
    • Condition semasa dipulangkan
    • Status baru aset (Available/Under Repair/Retired)
    • Notes (optional)
  5. Tekan "Confirm Return"
  6. Aset status akan kembali ke "Available" (atau status yang dipilih)
Tip: QR code ada pada setiap aset. Print dan lekat pada aset fizikal untuk mudah scan.

5. Dashboard

Dashboard menunjukkan overview sistem:

  • Total Assets: Jumlah semua aset
  • Available: Aset yang boleh dipinjam
  • On Loan: Aset yang sedang dipinjam
  • Overdue: Pinjaman yang terlambat
  • Overdue Loans List: Senarai pinjaman yang melebihi due date

6. Pengurusan Aset

6.1 Tambah Aset Baru

  1. Pergi ke menu Assets
  2. Tekan "Add Asset"
  3. Isi maklumat:
    • Asset Tag (contoh: LHP-01) - unique
    • Nama aset
    • Kategori (Laptop, Projector, Tablet, dll)
    • Brand, Model, Serial No (optional)
    • Notes (optional)
  4. Tekan "Save Asset"
  5. QR code akan auto-generate

6.2 Print QR Code

  1. Pergi ke Assets page
  2. Tekan icon QR pada aset yang nak print
  3. Modal akan buka dengan QR code besar
  4. Tekan "Print Label" atau guna browser print
  5. Lekat QR code pada aset fizikal

6.3 Edit/Delete Aset

  • Edit: Tekan icon pencil, ubah maklumat, save
  • Delete: Tekan icon trash, confirm (hanya untuk aset tanpa loan history)

7. Pengurusan Peminjam

7.1 Tambah Peminjam

  1. Menu Borrowers → "Add Borrower"
  2. Isi: Nama, ID Number, Department, Phone, Email
  3. Save

7.2 Edit/Delete Peminjam

  • Edit: Tekan icon pencil
  • Delete: Tekan icon trash (hanya jika tiada loan history)

8. Pinjaman (Loans)

8.1 View Active Loans

Menu Loans → tab "Active Loans" menunjukkan semua pinjaman yang sedang aktif.

8.2 Create New Loan (Manual)

  1. Menu Loans → tab "New Loan"
  2. Pilih aset dan peminjam
  3. Set tarikh pinjaman dan due date
  4. Isi condition dan notes
  5. Submit

8.3 Return Loan

  1. Active Loans → tekan "Return" pada loan
  2. Isi tarikh return, condition, status baru
  3. Confirm

8.4 Loan History

Tab "History" menunjukkan semua pinjaman (aktif, returned, overdue). Boleh filter by status dan date range.

9. Reports

  1. Menu Reports
  2. Pilih date range (optional)
  3. Tekan "Filter" untuk preview
  4. Tekan "Export CSV" untuk download
  5. Open CSV dalam Excel atau spreadsheet

10. Troubleshooting

Masalah Penyelesaian
Page blank / tak boleh load
  • Check phone connect ke WiFi yang sama
  • Clear browser cache
  • Cuba Incognito/Private mode
QR code scan tapi tak buka page
  • QR code mungkin ada IP lama - print semula
  • Check connection guna test.php
Database connection error
  • Restart computer (services auto-start)
  • Atau run start-system.bat
Tak boleh delete aset/peminjam Ada loan history - data tak boleh delete untuk audit trail
IP address berubah
  • Update config/db.php line 12
  • Run sync-to-server.bat
  • Print semula QR codes

11. Tips & Best Practices

  • Print QR codes dan laminate untuk tahan lama
  • Backup database secara berkala (mingguan/bulanan)
  • Change admin password selepas first setup
  • Train workers guna QR scan untuk speed
  • Check overdue loans setiap hari di dashboard
  • Set static IP untuk server kalau boleh (elak masalah IP berubah)

12. Sokongan

Untuk masalah teknikal atau pertanyaan:

  • Check test.php untuk verify connection
  • View Apache logs: C:\xampp\apache\logs\error.log
  • View MySQL logs: C:\xampp\mysql\data\*.err
  • Contact system administrator
